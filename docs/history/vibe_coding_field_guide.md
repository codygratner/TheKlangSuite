## ⚡ Universal Operational Protocols (Executive Summary)

1. **The Flash Orchestrator + Pro Subagents Engine:**
   - The main chat session stays permanently on Tier 2 Flash (sustainable daily driver). For heavy algorithmic proofs or multi-file architectural synthesis, the orchestrator autonomously spawns on-demand Tier 1 Pro subagents (`invoke_subagent(Model="pro")`), slashing quota burn by ~90% while keeping chat context lean.
2. **The Tri-Engine Subagent Pattern:**
   - Deploy 2 constructive subagents (`explore`, Flash) alongside 1 adversarial subagent (`contrarian`, Flash) to stress-test designs and derive the pragmatic 80/20 middle ground.
3. **The 2-Strike Factory Escalation:**
   - The factory floor has up to 2 attempts to resolve a compilation or test failure on Tier 2. If still failing, it hard-pauses, recommends a Tier 1 upgrade, and waits for user confirmation.
4. **The Asymmetric Sidecar Split:**
   - Keep chat responses terse and conversational (1–3 sentences); render rich interactive diagrams, tradeoff matrices, and visual mockups inside the N'kai sidecar canvas.
5. **The 0-Turn Cold Boot Invariant & Context Clues Architecture:**
   - Agents bootstrap from role-specific context clues (`context_clues_plan.md`, `context_clues_build.md`, `context_clues_subagent.md`) conforming to the universal 5-section standard, resuming operations in exactly 0 turns after a context refresh.
6. **Telescoping Institutional Memory (The Soul Harvest Standard):**
   - Stage raw notes and gotchas into `.agents/pipeline/staging/souls/` post-flight (0 token cost). Batch-distill into permanent RFCs during deep docs passes (`/update-docs --deep`).
