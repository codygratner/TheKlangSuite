# Creative Lore & Worldbuilding

This directory serves as the repository archive for creative lore, character chronicles, worldbuilding stories, and in-universe mythology of **The Klang Suite**, **New Klang City**, **ToadTracker**, and **The Cosmic Codex**.

- **Local Only (Gitignored)**: All markdown chronicles and lore documents in this directory (except this README anchor) are strictly ignored by Git. Creative worldbuilding remains preserved on your local workstation without cluttering public production commits.
- **Obsidian Vault Mirror**: All lore files created here are mirrored into the Obsidian Vault under `TheKlangVault/Lore/` and `TheKlangVault/Docs/lore/`.
- **Inter-Project Lore Dispatch**: Transmissions between the Stellar Zenith (Vault/Codex) and the Subterranean Foundry (Mayor Toad/KlangToad) flow through `docs/lore/dispatch/`.
